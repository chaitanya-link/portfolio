//02 Selected work

Three projects, built end to end.

001 / 003 AI / Agents

AutoPitch

An agentic cold-outreach engine that researches before it writes. It scrapes a lead's own site, retrieves the most relevant passages with RAG, and has Gemini draft a personalised email grounded in that context — scoring its own confidence and routing anything uncertain to human review instead of guessing.

  • Six-stage pipeline: scrape → chunk & embed → retrieve (pgvector) → draft → confidence-gate → send → reply-match
  • Real email threading — replies matched back via In-Reply-To / References headers
  • Respects robots.txt and paces sends with a hard daily cap — built for deliverability, not a demo

002 / 003 Browser Extension / AI

NeuralThreads

A cross-platform memory layer for AI chat. It reads a conversation straight off the page, compresses it through a RAG pipeline into a clean summary, and injects that context into a brand-new chat on a different platform — so Claude can pick up exactly where ChatGPT left off.

  • Capture → Compress → Store → Inject: real chunking, embeddings and retrieval, not a copy-paste trick
  • Works across ChatGPT, Claude, Gemini and Perplexity with no API keys — reads what is already on screen
  • Encrypted, searchable session library reachable from any device
